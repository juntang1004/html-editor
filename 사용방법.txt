HTML Slide Studio · Windows 휴대용 버전

1. ZIP 파일을 마우스 오른쪽 버튼으로 눌러 '모두 압축 풀기'를 선택하세요.
2. 압축을 푼 폴더의 '실행.cmd'를 더블클릭하세요.
3. 브라우저가 열리면 'HTML 열기'로 편집할 HTML 파일을 선택하세요.

Node.js와 API 설정이 포함되어 있습니다. Codex나 Node.js를 따로 설치하거나
API 키를 다시 입력할 필요가 없습니다. Windows 10/11 64비트(x64)용입니다.
Chrome 또는 Edge 브라우저를 사용하세요. Mac용 패키지는 아닙니다.

AI 명령은 인터넷 연결이 필요하며, 포함된 API 계정의 사용료가 발생합니다.
기본 글자·도형·슬라이드 편집은 인터넷 없이도 사용할 수 있습니다.
가져온 HTML이 외부 이미지·폰트·스크립트를 사용하면 해당 자료에 인터넷이 필요할 수 있습니다.

■ 저장과 이동
- 편집 후 'HTML 저장' 또는 '프로젝트 저장'으로 파일을 다운로드하세요.
- 저장한 HTML은 다른 컴퓨터에서 발표하거나 이 편집기로 다시 열 수 있습니다.
- 발표용 HTML에는 API 키가 들어가지 않습니다.
- 브라우저의 임시 저장 내용은 이 ZIP에 포함되지 않습니다.
- 편집기를 전달할 때는 압축 파일 전체를, 강의만 전달할 때는 저장한 HTML을 전달하세요.

■ 실행·종료
- ZIP 안에서 바로 실행하지 말고 반드시 전체 압축을 풀어주세요.
- runtime, public, 설정 파일은 같은 폴더에 유지하세요.
- 프로그램을 다시 실행하면 이미 실행 중인 같은 폴더의 편집기를 엽니다.
- 작업 파일을 저장한 후 '프로그램 종료.cmd'를 실행하면 백그라운드 서버가 종료됩니다.
- 해당 폴더를 옮기기 전에는 프로그램을 종료하세요.

■ AI 편집
- AI → 디자인 · 글자 · 배치: '전체 제목을 44px로 통일해줘'
- AI → 액션 · 애니메이션: '이 도형을 클릭하면 나타나게 해줘'
- 변경 제안과 미리보기를 확인한 뒤 적용하세요. Ctrl+Z로 되돌릴 수 있습니다.
- 자료 검색은 ChatGPT 대화에서 진행하고 결과 HTML을 가져오세요.
