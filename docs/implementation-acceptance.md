# 전체 구현 완료 기준

원본 배포 폴더와 API 키는 보존한다. 개발본은 Rust/Tauri 데스크톱 셸 및 기존 HTML 렌더러를 사용한다.

| 요구 | 완료 검증 |
|---|---|
| 썸네일 일치 | 부모 CSS, grid/flex, SVG를 가진 고정 QA 문서의 캔버스/썸네일 배치 비교 |
| 패널 폭 | 양쪽 분할선 포인터/키보드 조절, 최소 폭, 저장된 폭 복원 |
| 편집 UI | 파일 메뉴·리본·서식·액션·AI 탐색 및 작은 창 레이아웃 확인 |
| 단축키 | 캔버스/툴바 Delete, 입력 중 Delete 보호, 실행취소/복사/저장 |
| 다중 선택 | Shift/Ctrl 및 영역 선택, 다중 이동/삭제/복사, 실행취소 |
| 전체 테두리 | 선택색과 구분, 선택 변경 후 유지, 끄기, HTML/PDF 미포함 |
| 파일 | 열기/저장/다른 이름 저장, 취소·오류 처리, 다시 열기, PDF |
| AI | 기존 액션 포함한 문맥, 추가/수정/삭제, 원본 CSS 시간 수정, 200→2000 ms, 미리보기·적용·되돌리기 |
| 순차 실행 | 검정→밝아짐 이후 그래프 데이터 증가, 축/라벨 보존, 재생/재실행 |
| 갤러리 | 오프라인 효과 목록·검색·분류·미리보기·적용·저장, 모션 감소 |
| 음성 제거 | 마이크 버튼과 음성 인식 경로 없음 |
| 결과물 | Windows exe 빌드·실제 실행, 실행 안내, 알려진 한계 |

AI 자동 검증은 모의 응답으로 수행한다. API 과금 없이 통과한 테스트를 실제 모델의 자연어 이해 성공으로 보고하지 않는다. 사용자 키를 산출물에 포함하지 않는다.

작업 배정: UI `feature/editor-ui` (Claude Sonnet 5.5 high), AI/갤러리 `feature/animation-ai` (Claude Opus 5.5 high), 데스크톱 셸 별도 Codex 담당, 통합 및 독립 QA 주 담당.
