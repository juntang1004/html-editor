## 보존 및 설정

원본 배포 폴더를 편집하지 않았다. 사용자가 명시적으로 승인한 기존 API 설정만 `%APPDATA%/com.slidestudio.editor/.env.local`에 재사용했다. 배포 폴더에 `.env`, 키·인증 파일은 없으며 릴리스 메타데이터도 `apiConfigurationIncluded:false`이다. GitHub에 업로드하지 않았다.

## 구현 범위의 한계

상대 경로 로컬 자산을 자동 인라인화하지 않는다. 임의 JavaScript 전체를 자연어로 다시 작성하지 않는다. 이미지/canvas 그래프 안의 개별 데이터 요소는 인식하지 않는다. 복잡한 SVG 데이터 판별은 휴리스틱이며 `data-ss-mark`/`data-ss-axis`로 명시할 수 있다. 상세 사용법은 `user-guide.ko.md` 참고.

## 작업 분담과 후속 운영

Paseo로 Claude Sonnet5.5 high(UI), Opus5.5 high(AI/갤러리)를 별도 Git 작업 폴더에 배정했다. Codex가 Rust 데스크톱, 독립 QA, 병합·수정·최종 검증을 수행했다. 사용자 사용량 우려 후 Claude 두 작업의 idle 상태를 확인하고 추가 호출을 중단했다.

사용자 선호를 작업팀 지침에 반영했다: 앞으로 Claude는 초기 구현 중심, Codex는 통합·QA·수정·패키징 중심. 큰 단계 완료 후 실제 계정 한도와 초기화 시각을 조회하고 재배정한다. 모델의 자기 보고나 토큰 수를 잔여 구독 한도로 오인하지 않는다.
