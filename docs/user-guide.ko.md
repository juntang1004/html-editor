# HTML Slide Studio 0.3 — 사용 안내

`HTML Slide Studio.exe`를 실행하세요. 설치 없이 실행하는 Windows x64 폴더형 앱입니다. `resources` 폴더는 실행 파일 옆에 두세요. 이 컴퓨터에서는 WebView2와 기존 API 설정 연결을 확인했습니다.

## 편집

- **파일 → 열기**: HTML 또는 `.studio.json` 프로젝트를 엽니다. 같이 제공한 `예제-슬라이드.html`로 먼저 확인할 수 있습니다. 예제의 수치는 기능 검증용 임의 값입니다.
- 글자는 더블클릭해서 편집하고, 개체는 드래그해서 이동합니다.
- 빈 곳에서 사각형을 드래그하면 그 안에 완전히 들어온 개체들이 선택됩니다. Ctrl/Shift+클릭은 선택을 추가·해제합니다.
- Delete/Backspace 삭제, Ctrl+C/X/V 복사·잘라내기·붙여넣기, Ctrl+Z/Y 실행취소·다시 실행, 방향키 이동(Shift: 큰 이동)을 지원합니다. 글을 입력하는 동안에는 개체 단축키가 끼어들지 않습니다.
- 좌우 패널 경계선을 끌어 너비를 바꿉니다. 경계선을 더블클릭하면 기본값으로 돌아갑니다.
- **보기 → 모든 개체 테두리**: 전체 개체는 파란 점선, 선택한 개체는 주황 실선으로 구분됩니다. 선택을 바꿔도 유지되며 저장된 발표·PDF에는 나오지 않습니다.

## 파일과 PDF

- **저장**(Ctrl+S)은 현재 문서 형식으로 저장합니다. 처음 저장할 때 위치를 선택합니다.
- **다른 이름으로 저장**(Ctrl+Shift+S)은 새 위치를 선택합니다.
- **프로젝트 파일로 저장**은 편집 상태를 JSON으로 보관합니다. **HTML로 내보내기**는 다른 브라우저에서도 재생 가능한 HTML을 만듭니다.
- **PDF로 내보내기·인쇄**(Ctrl+P)에서 PDF 프린터/저장 대상을 선택합니다. 문서의 모든 슬라이드가 한 장씩 출력되며 편집 UI와 선택 테두리는 제외됩니다.
- 저장 취소·실패 시 미저장 상태를 유지합니다. 새 문서를 열었을 때 이전 작업은 Ctrl+Z로 되돌릴 수 있습니다.

## 효과와 AI

- 오른쪽 **효과** 탭에는 53개 효과가 있습니다. 검색·분류 → 카드 미리보기 → 개체 선택 → 적용 순서로 사용합니다.
- 여러 개체를 선택하면 차례로 적용할 수 있습니다. 시작 조건은 슬라이드 진입, 클릭, 마우스 올리기, 이전 효과 완료 후입니다.
- **액션** 탭에서 기존 효과를 수정·삭제하거나, 원본 CSS 애니메이션의 재생 시간을 직접 바꿉니다.
- **AI → 액션·애니메이션**에서 예를 들어 다음처럼 입력하세요.
  - `0.2초 애니메이션을 2초로 바꿔줘.`
  - `검은 화면에서 1초 동안 밝아진 다음 그래프가 2초 동안 자라게 해줘.`
- 제안을 미리 확인하고 **적용**하세요. 적용 후 Ctrl+Z로 되돌릴 수 있습니다.
- **기본 해석기만 사용**을 켜면 지원되는 시간 변경·삭제·효과 추가·순서 연결을 오프라인으로 처리합니다. UI에 API 제안과 오프라인 해석을 구분해 표시합니다.
- **동작 줄이기**는 과도한 이동·회전 등을 줄이며 발표·HTML 내보내기에도 반영됩니다.

## 검증 범위와 제한

- CSS·이미지 등이 포함된 단일 HTML이 가장 정확합니다. 상대 경로로 연결된 로컬 자산을 자동으로 묶는 기능은 아직 없습니다.
- 기존 CSS 애니메이션과 앱의 액션은 수정할 수 있습니다. 임의 JavaScript 코드 전체를 자연어로 다시 쓰는 기능은 제공하지 않습니다.
- SVG/HTML 그래프의 데이터 요소를 감지합니다. 이미지·canvas 그래프 안의 개별 막대는 분리할 수 없으며 전체 개체 효과를 사용합니다. 축 인식이 어려운 특수 SVG는 별도 확인이 필요합니다.
- 브라우저 버전에서는 저장이 다운로드 방식입니다. Windows 앱에서는 실제 파일 열기·저장 대화상자를 사용합니다.
- 36개 단위·서버 테스트, 47개 브라우저 테스트, 2개 Rust 테스트 및 Windows 실행 검사를 통과했습니다. 실제 API의 시간 변경·순차 효과 2개 사례도 확인했습니다.
- 실제 Windows 파일·PDF 대화상자 수동 조작은 화면 도구 시간 초과로 검증하지 못했습니다. 파일 쓰기 로직과 PDF 레이아웃은 자동 테스트로 확인했습니다.

API 키는 이 배포 폴더에 포함되지 않습니다. 이 컴퓨터의 승인된 설정은 `%APPDATA%\com.slidestudio.editor\.env.local`에 따로 보관됩니다. 앱의 AI 요청은 기존 OpenAI API 계정 사용량에 포함됩니다.
